# PayPal AI Hackathon — Official Rules Checklist

Tick each box before submitting. Deadline: 13 Nov 2026, 4:00 AM MYT. Judging ends: 16 Dec 2026 MYT.

## What to build

- [ ] The PayPal developer platform (sandbox) is CENTRAL to the app.
- [ ] An AI tool or model is used inside the app.
- [ ] The project was newly created after 1 Oct 2026.

## What to submit

- [ ] English text description of the features.
- [ ] Working demo: a hosted URL.
- [ ] Working demo: full setup steps in the README.
- [ ] Public GitHub repo containing all source code.
- [ ] Open-source license (MIT) in the repo and visible in the repo's About section.
- [ ] Public YouTube video, under 3 minutes, showing the app working end to end.
- [ ] Video has no copyrighted music and no third-party trademarks.
- [ ] README has a testing section with sandbox test-account logins.
- [ ] Judges get free, unrestricted access until judging ends (16 Dec 2026 MYT).

## Judging

- [ ] Stage 1 (pass/fail): fits the theme, and really uses PayPal APIs.
- Stage 2 (equal weight). Ties are broken in this order:
  1. [ ] Technical implementation
  2. [ ] Design
  3. [ ] Potential impact
  4. [ ] Innovation
  5. [ ] Presentation
- [ ] AI may be used in judging, so the README must be clear and well structured.

## After the deadline (official rules, Section 5)

The rules say: "Once the Submission Period has ended, you may not make any changes or alterations to your Submission."

- [ ] After the deadline, `main` is frozen. Tag the submitted commit (`git tag submission`) and push the tag (`git push origin submission`).
- [ ] Only maintenance is allowed: restarting Render, renewing keys in Render's settings, fixing judge logins. No code or README changes.
- [ ] If the code ever needs a fix, ask Devpost in writing first, and wait for their answer.

## Prizes

- A project can win at most one grand prize OR one honourable mention, plus one sponsor prize.
- [ ] Sponsor prize target: AG Grid — use the free Community version.
